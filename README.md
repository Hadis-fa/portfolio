# Portfolio

My personal portfolio website — clean, simple, and built to be easy to update.

🔗 **Live:** [hadisf.vercel.app](https://hadisf.vercel.app)

## Tech Stack

- **React** + **Vite** — frontend framework and build tool
- **CSS** — custom styling with CSS variables
- **Vercel** — hosting and CI/CD

## Features

- Responsive design for desktop and mobile
- Smooth scroll animations with the Intersection Observer API
- Component-based architecture
- Centralized content in `src/data/content.js` for easy updates

## Getting Started

```bash
npm install
npm run dev
```

To customize the content, edit `src/data/content.js`.
